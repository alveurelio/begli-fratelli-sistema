📋 GUÍA INSTALACIÓN — Cliente para Vercel + Firebase

PASO 1: Crear proyecto Firebase

1. Entra console.firebase.google.com
2. Click "Crear proyecto" → nombre: "begli-fratelli"
3. Espera a que se cree
4. Entra al proyecto
5. Izquierda → "Realtime Database"
6. Click "Crear base de datos"
7. Ubicación: elegir cercano (ej: us-central1)
8. Reglas: selecciona "Comenzar en modo de prueba"
9. Confirma

PASO 2: Obtener credenciales

1. Click engranaje (⚙) arriba izquierda → "Configuración del proyecto"
2. Tab "General"
3. Abajo → "Aplicaciones de Firebase" → click  (web)
4. Nombre: "begli-web"
5. COPIA el objeto firebaseConfig (tiene todos los valores)
6. Reemplaza en código arriba donde dice:
   const firebaseConfig = { ... }

PASO 3: Configurar reglas Firebase (IMPORTANTE)

En Realtime Database:
1. Tab "Reglas"
2. Reemplaza con esto:
{
  "rules": {
    "pedidos": {
      ".read": true,
      ".write": true
    },
    "usuarios": {
      ".read": true,
      ".write": true
    }
  }
}
3. Click "Publicar"
(NOTA: esto es para demo. Producción = seguridad más estricta)

PASO 4: Subir a Vercel

1. Guarda este archivo como "cliente.html"
2. Entra vercel.com → Sign in con GitHub
3. Click "Add New..." → "Project"
4. "Import Git Repository" → crea repo GitHub con archivo
   (O sube carpeta sin Git → "Deploy"
5. Vercel publica automático → te da link tipo:
   https://begli-fratelli.vercel.app/cliente.html
6. Para mesa específica: 
   https://begli-fratelli.vercel.app/cliente.html?mesa=3
7. Genera QR ese link → imprime en mesa

PASO 5: Generar QR por mesa (gratis)

1. Entra qr-code-generator.com
2. URL: https://tudominio.vercel.app/cliente.html?mesa=1
3. Descarga imagen QR
4. Imprime 1 por cada mesa
5. Pega en mesa

Verificar funcionamiento

1. Abre cliente.html en navegador
2. Agrega platos → click "Pedir"
3. Entra Firebase Console → Realtime Database
4. Deberías ver "pedidos" con el pedido que mandaste
5. ¡Funciona! Caja y Cocina pueden leer eso

Próximo paso: Caja y Cocina

Cuando cliente funcione, creamos caja.html y cocina.html que LEEN de la misma base datos Firebase.
